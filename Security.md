# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately to the repository owner rather than opening a public issue.

Please include:

- Description of the vulnerability
- Steps to reproduce it
- Potential security impact
- Suggested mitigation, if known

Do not include passwords, API keys, or other sensitive information in reports.

## Supported Versions

Security fixes are currently provided for the latest version of the project.
